# ONG Esperança

Projeto acadêmico desenvolvido na disciplina de Desenvolvimento Front-end.

## Objetivo

Criar uma aplicação web para uma ONG fictícia, permitindo apresentar informações institucionais, divulgar projetos e realizar cadastros de voluntários e doadores.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SweetAlert2
- Git e GitHub

## Funcionalidades

- Navegação em formato SPA
- Exibição dinâmica de projetos
- Formulário com validação
- Armazenamento de cadastros no LocalStorage
- Mensagens de sucesso e erro com SweetAlert2
- Layout responsivo

## Estrutura do projeto

- `html/` - páginas e estrutura principal
- `css/` - estilos da aplicação
- `js/` - scripts JavaScript
- `imagens/` - recursos visuais
